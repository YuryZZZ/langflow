# Quick Notes - opencode

## Ver05.1 FLUID Quick Reference

### Commands
- /auto - Auto-route by complexity
- /fast - Skip validation
- /route - Check complexity only
- /split - Decompose task

### Routing
- 1-3 = Fast (<5s)
- 4-6 = Standard (<15s)
- 7-10 = Full (<30s)

### FLUID Syntax
- @coder(pool=CODING_STANDARD)
- @validator(pool=VALIDATION, exclude=deepseek)
